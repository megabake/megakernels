# megakernels

Megakernels generated by [MegaBake](https://github.com/megabake/megabake). Each one is a
whole model step — one decode token or one prefill — compiled from `torch.compile`'s FX
graph into a single persistent CUDA kernel (CuTe DSL).

**How to read it.** Batch 1, bf16. Each time is the median complete call (host and GPU,
CUDA events around the call) of the fastest MegaBake variant. The speedup columns are
*baseline time ÷ MegaBake time*, so values above 1× mean MegaBake is faster. Each row comes
from the newest benchmark that measured that model against a torch.compile baseline, and
"—" means that run did not measure the baseline. *MIG 3g.71gb* is a 3/7 slice of one H200.

- **torch.compile**: `torch.compile(model, fullgraph=True)` with the default Inductor backend.
- **torch.compile + CUDA graph**: the faster of Inductor's `mode="reduce-overhead"` and the
  whole step captured into one `torch.cuda.CUDAGraph`. This is the strongest launch-overhead
  baseline and the fairest comparison.
- **Launches**: kernel launches per call, CUDA-graph baseline → MegaBake.
- **Decode** advances a static KV cache by one token, with context up to 128 tokens unless the
  report says otherwise. **Prefill** runs a short prompt (see `prompt_tokens` in the report).

## Layout

```
kernels/<org>--<model>/<gpu>/<mode>/
    module.py          the generated kernel (CuTe DSL Python)
    source_map.json    kernel source → FX node mapping
    report.json        the benchmark it came from
archive/<run>/...      every benchmark run so far: report.json and module.py per mode
```

The archive holds 416 kernels from 292 benchmark runs. Each published
`report.json` records its source artifact, measurement time and `megabake_commit`: the
newest MegaBake commit at that time. The working tree may have had changes on top of it.

## Using a kernel

Kernels import `megabake.runtime` and MegaBake's CuTe bodies, so they run against the MegaBake
revision that generated them (`8b94b7c`, `c2b4d57` for the table above).
To regenerate one on your own GPU:

```sh
git clone https://github.com/megabake/megabake && cd megabake
python benchmarks/full_model.py --model Qwen/Qwen2-0.5B --modes decode --out out/
```
